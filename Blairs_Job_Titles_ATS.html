What these percentages mean

Each score is the estimated ATS potential of a resume that could be created from index.html for that job title.

Example: “MySQL Database Administrator — 92%” means: if Blair builds a DBA-focused resume from the Percona/Galera/PXC/Associate DBA TSE material already on index.html, that resume could realistically land in the low-90s ATS match band for many MySQL DBA postings — not that the current multi-role portfolio page already scores 92% against every DBA job.

Strongest tailored-resume families:
  • L3 / managed hosting — densest production bullets (Liquid Web, Nexcess).
  • Linux / RHCE — 20y servers + RHCE6 support a clean Linux admin resume.
  • MySQL / Percona HA — PXC/Galera/XtraBackup/PMM form a DBA-ready cut.
  • AWS / OpenStack hybrid ops — certs + hybrid cloud title support cloud resumes.
  • WP / Woo / Magento hosting — multi-year e-comm full-stack material.
Scoring rules:
  • Source = facts on index.html only (no invented experience).
  • Score = estimated ATS potential of a targeted resume cut for that title.
  • Hard ceiling 94% — employer keyword variance prevents honest 95%+ claims.
  • Dense bullet families score higher; thin/adjacent families score lower.
  • Gaps (K8s lead years, Azure/GCP primary, formal sales certs) reduce potential.
Not measuring:
  • How the live multi-role portfolio page ranks in one generic ATS pass
  • Interview probability or offer rates
  • Official vendor ATS outputs (Workday, Greenhouse, etc.)
  • Roles that would require fabricating skills not on index.html

Methodology

For each job title, this board asks: If a resume were written only from facts already on index.html, optimized for that title’s typical ATS keywords, what match band is realistic? Dense families (L3 hosting, Linux, MySQL HA, AWS/OpenStack, WP/Magento/Woo, technical sales language) support higher potential scores. Adjacent or thin families (Azure-primary, pure K8s lead, formal SecOps) score lower because index.html does not provide enough exclusive evidence without inventing experience.

Hard rule: no score ≥ 95%. Real ATS systems differ by employer keyword lists and formatting; claiming 95%+ would overstate certainty even for the strongest cuts.

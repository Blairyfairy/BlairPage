Methodology and caveats

This page is intentionally a live signal board, not a fake “real-time” static file. It tries to refresh from official, browser-accessible, no-key endpoints first. That works especially well for Cloudflare, DigitalOcean, Oracle Cloud Infrastructure, GitHub-based open ecosystems, and some public-market quote proxies. Where providers do not expose a clean public browser endpoint, the page falls back to a baseline strategic profile and official dashboard links instead of inventing data. For Mirantis, which is privately held, the page uses public product releases, known funding history, acquisitions, k0s GitHub activity, and official product pages rather than fabricated revenue.

The “Gartner-style” matrix is original editorial synthesis. It is inspired by quadrant-style evaluation logic, but it is not Gartner content and should not be presented as a Gartner Magic Quadrant.

Refresh cache window: six hours for ordinary page loads, with an immediate refresh available through the Refresh now button. This keeps the page fast while still behaving like a live cloud-provider board.

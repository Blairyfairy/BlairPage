# Blair Page | AWS Certified Portfolio

Personal portfolio and resume site for **Blair Page** (Burness Drake McCoy).

**RHCE6 · AWS Certified**

Live site: [blairyfairy.github.io/BlairPage](https://blairyfairy.github.io/BlairPage)

---

## Overview

A single-page, fully responsive portfolio built with pure HTML, CSS, and JavaScript.  
Designed for both desktop and mobile, with strong focus on:

- Stable layout across all viewport sizes
- No white-flash / background flicker on resize or theme change
- Expandable professional experience sections
- Light / dark theme toggle
- Clean presentation of certifications, education, and selected projects

---

## Features

- **Responsive design** — works on desktop, tablet, and mobile without a separate mobile page
- **Theme toggle** — light and dark modes with glassmorphism-style cards
- **Expandable job experience** — + / − toggles for detailed role descriptions
- **Education & certifications** — including AWS, RHCE, and related credentials
- **Special project cards**:
  - Blair’s Picks (fashion editorial)
  - Weight Loss Journey
  - The Brutal Darksides (metal command center)
- **Brand / client marquee** — seamless horizontal slider of enterprise and platform logos
- **Social & contact links** — LinkedIn, GitHub, Linktree, Discord, WhatsApp, and more
- **Performance-minded CSS** — reduced motion support, scroll stability, and anti-flicker locks

---

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, extensive media queries)
- Vanilla JavaScript
- No frameworks or build tools required
